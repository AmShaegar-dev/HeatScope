# HeatScope — монитор нагрева ПК

Программа для Windows, которая показывает, **какие процессы грузят систему и сколько градусов они добавляют** к температуре процессора и видеокарты. Умеет ставить процессы на паузу, завершать их и защищает критически важные компоненты Windows.

## Возможности

| Функция | Описание |
|---|---|
| Датчики | Температура и загрузка CPU/GPU, мощность, память. AMD / Intel / NVIDIA |
| Вклад в нагрев | Оценка «+X °C» для каждого процесса в реальном времени (термомодель) |
| Точный замер | Кнопка «Проверить вклад (20 с)» — замораживает процесс и измеряет фактическое падение температуры |
| Пауза | `NtSuspendProcess` / `NtResumeProcess` — процесс перестаёт выполняться, память остаётся занятой |
| Завершение | Обычное и вместе с дочерними процессами |
| Защита | Блокировка критических процессов (BSOD), предупреждение для системных/оболочечных |
| Что делает процесс | Путь, командная строка, издатель, цифровая подпись, родитель, службы, сетевые соединения, окно |
| Сортировка | По вкладу в нагрев, автоматически |

### Мягкий режим охлаждения

Кнопка **«Охладить (5 мин)»**:

- ставит на паузу до 5 самых «горячих» разрешённых процессов (именно пауза, не завершение);
- ограничивает максимальное состояние CPU до 99% (отключает турбо-буст);
- через 5 минут автоматически возобновляет процессы и возвращает настройки питания;
- не трогает критические процессы, оболочку, терминалы и саму HeatScope.

## Как считается «сколько градусов добавляет процесс»

Прямого способа измерить вклад одного процесса в температуру не существует — датчик показывает только общий нагрев. Поэтому HeatScope считает вклад относительно **плавающей базы**:

```
база  = минимальная устойчивая температура за последние ~15 минут
подъём = текущая температура − база
вклад процесса = подъём × (загрузка процесса / общая загрузка)
```

- Самая низкая наблюдённая температура (отдельно для CPU и GPU) принимается за **0 °C**.
- Как только система остывает, база опускается, и все значения **пересчитываются вниз** — вплоть до нуля.
- База считается по сглаженным значениям, чтобы одиночный выброс датчика её не сдвинул.
- В карточке «Термомодель» видно: `база 42.0 °C · сейчас 55.0 °C`.
- Точность — **±1–2 °C**, это оценка, а не измерение.
- Для точного ответа используйте кнопку **«Проверить вклад»**: процесс замораживается на 20 секунд, температура сравнивается до/после.

## Требования

- Windows 10/11 x64.
- **Права администратора** — для чтения датчиков и управления чужими процессами.
- **Драйвер PawnIO** — подписанный драйвер, через который LibreHardwareMonitor читает температуры. Установщик Windows ставит его автоматически (галочка включена по умолчанию, тихий режим). Если драйвер отсутствует, приложение может установить его само кнопкой в шапке.
- Без администратора/драйвера программа всё равно работает: список процессов, загрузка CPU/GPU, память, пауза и завершение (для своих процессов), но температуры недоступны.

## Защита критических процессов

Заблокированы навсегда (завершение = BSOD или обвал оболочки): `System`, `Registry`, `smss`, `csrss`, `wininit`, `winlogon`, `services`, `lsass`, `lsaiso`, `dwm`, `fontdrvhost`, `MsMpEng`, `audiodg`, сама HeatScope и все процессы с флагом `ProcessBreakOnTermination`.

Требуют подтверждения: `svchost`, `explorer`, `sihost`, `spoolsv`, `TrustedInstaller`, `SearchIndexer`, `dwm`-соседи и т.п.

## Сборка

```powershell
# SDK .NET 8 (если ещё не установлен)
./build.ps1
```

`build.ps1` собирает самодостаточный exe в `dist\HeatScope.exe` — на целевой машине .NET не нужен.

Ручная сборка:

```powershell
dotnet build src\HeatScope\HeatScope.csproj -c Debug
dotnet publish src\HeatScope\HeatScope.csproj -c Release -r win-x64 --self-contained true `
  -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o dist
```

## Структура

```
src/HeatScope/
  Models/          ProcessRow, HardwareSnapshot
  Services/
    HardwareSampler.cs   — датчики через LibreHardwareMonitor
    ProcessSampler.cs    — процессы, CPU, GPU, RAM
    GpuUsageProvider.cs  — загрузка GPU по процессам (GPU Engine counters)
    ThermalModel.cs      — МНК-модель и оценка вклада
    ProcessGuard.cs      — защита и завершение
    ProcessDetails.cs    — «что делает процесс»
    NetworkProvider.cs   — TCP-соединения процесса
    NativeMethods.cs     — P/Invoke suspend/resume/critical
  MainWindow.xaml(.cs)   — интерфейс
```

## Ограничения

- Вклад в температуру — статистическая оценка; при резких скачках нагрузки возможны выбросы.
- Загрузка GPU по процессам берётся из счётчиков Windows «GPU Engine» — поддерживаются все вендоры, но у старых драйверов счётчики могут отсутствовать.
- Заморозка системных служб может привести к зависанию системы — для них показывается предупреждение.
- Датчики температуры зависят от поддержки железа драйвером PawnIO; экзотические ноутбуки могут отдавать не все значения.

## Установка и ярлыки

Готовый установщик: `release\HeatScope-Setup-0.1.1.exe`

- мастер установки показывает страницу **«Выбор папки установки»** (по умолчанию `C:\Program Files\HeatScope`), путь можно изменить;
- создаёт ярлыки в меню «Пуск» и (по желанию) на рабочем столе;
- ставит деинсталлятор;
- **устанавливает драйвер датчиков PawnIO автоматически** (галочка «Установить драйвер датчиков PawnIO» включена по умолчанию, тихий режим `-install -silent`);
- при первом запуске приложение само запрашивает права администратора (можно отказаться и работать в ограниченном режиме);
- если драйвер не установлен, в шапке появляется кнопка его установки (скачивает и ставит без мастера).

Портативный вариант: просто скопировать `dist\HeatScope.exe` на любую машину с Windows 10/11 x64.

Сборка установщика:

```powershell
./build-installer.ps1
```
## Linux / Ubuntu

Есть отдельная версия для Linux: Avalonia UI + данные из `/proc` и `/sys/class/hwmon` (без Windows-драйверов).

```bash
# Ubuntu/Debian: установка из .deb
sudo apt install ./heatscope_0.1.1_amd64.deb
heatscope-root

# или из архива
tar -xzf HeatScope-0.1.1-linux-x64.tar.gz -C heatscope && cd heatscope
bash install.sh
```

Подробности и ограничения (GPU по процессам, hwmon, root): [README-LINUX.md](README-LINUX.md).

Кросс-сборка с Windows: `./build-linux.ps1` → `release/HeatScope-0.1.1-linux-x64.tar.gz`.
